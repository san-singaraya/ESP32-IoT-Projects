# ESP32-IoT-Projects
ESP32-IoT-Projects is a collection of practical IoT and embedded systems projects developed using the ESP32, Arduino, sensors, actuators, LCD displays, and Wokwi simulation. This repository demonstrates basic to intermediate embedded programming, hardware interfacing, sensor data monitoring, and real-time output display.

# ESP32 Embedded Systems & IoT Projects

A collection of practical **ESP32 embedded systems and IoT projects** developed using **Arduino C/C++ and Wokwi simulation**. This repository demonstrates fundamental hardware interfacing, sensor integration, digital I/O, LCD communication, and real-time monitoring.

## 📁 Project Structure

Each project contains the required simulation files and source code, including:

- `sketch.ino` – Arduino source code
- `diagram.json` – Wokwi circuit configuration
- `libraries.txt` – Required libraries
- `wokwi-project.txt` – Wokwi project information

## 🔗 Wokwi Simulations

Each project includes its corresponding Wokwi simulation link for testing and demonstration.
